# 🎧 AURA MUSIC — Мобильное музыкальное приложение для Android

> Премиальное музыкальное приложение со стильным тёмным интерфейсом, чистым аппаратным звуком, полноценной поддержкой офлайн-режима, плейлистами, умными загрузками и поддержкой экрана блокировки.

---

## 📲 Как скачать и установить прямо на телефон из браузера (Google Chrome / Яндекс)

### ⚡ Быстрая установка (1 клик):
1. Откройте репозиторий в браузере на вашем телефоне (Google Chrome, Samsung Internet и др.).
2. Нажмите на файл **[aura-music-debug.apk](aura-music-debug.apk?raw=true)** и выберите **«Download»** (или «Скачать»).
3. Либо перейдите во вкладку **Releases** и скачайте `aura-music-debug.apk`.
4. Когда файл скачается, нажмите **«Открыть»**.
5. Если система попросит разрешение: нажмите **«Настройки» → «Разрешить установку из этого источника»**.
6. Нажмите **«Установить»** — ярлык **AURA** появится на вашем рабочем столе!

## 🌟 Основные возможности

### 🎵 1. Реальный аппаратный плеер
* Настоящее воспроизведение аудиофайлов MP3 на максимальной аппаратной громкости без потери качества.
* Плавная перемотка (скраббинг) с отображением точного прошедшего и оставшегося времени.
* Фоновое воспроизведение при заблокированном экране и управление через панель уведомлений Android (`MediaSession`).

### 🔀 2. Умная очередь, Shuffle и Repeat
* **«Играть следующим»** и **«Добавить в очередь»** для любого трека.
* Возможность переставлять треки в очереди выше/ниже стрелками.
* **Честный Shuffle**: случайный порядок без дубликатов, фиксирующий текущую композицию.
* **Режимы повтора**: Повторять всё (`ALL`), повторять один трек (`ONE`), без повтора (`OFF`).

### 📂 3. Плейлисты и медиатека
* Создание, переименование и удаление плейлистов.
* Добавление любых песен в плейлисты из меню опций `...`.
* Ручная сортировка треков внутри плейлиста (вверх/вниз).
* Запуск прослушивания с любого выбранного трека.

### ❤️ 4. Любимые треки и Умные загрузки
* Быстрый лайк в плеере, карточках и списках.
* Раздел **«Любимые треки»** с кнопками «Слушать всё» и «Перемешать».
* **Умные загрузки**: автоматическое офлайн-кэширование понравившихся песен в память устройства (IndexedDB).

### 💾 5. Импорт собственной музыки
* Кнопка импорта файлов на вкладке профиля позволяет загрузить любые аудиофайлы с телефона в память приложения. Они сохраняются навсегда даже после перезагрузки.

### 🔍 6. Быстрый поиск
* Мгновенный поиск по названию песни, исполнителю, названию альбома или жанру.
* Быстрые фильтры по жанрам: Поп, Хип-хоп, Рок, Электроника, R&B, Джаз.

### ⚙️ 7. Настройки и персонализация
* **OLED-режим**: чистый глубокий чёрный цвет (`#000000`) для экономии батареи на AMOLED/OLED-экранах.
* **Выбор качества звука**: 320 kbps (Hi-Res), 256 kbps, 128 kbps.
* **Crossfade**: плавное сведение между треками.

### 📱 8. Удобное закрытие экрана плеера
Экран «Сейчас играет» легко сворачивается:
1. Кнопкой со стрелкой вниз.
2. Свайпом или нажатием по верхней планке (drag-pill).
3. Нажатием на заголовок «СЕЙЧАС ИГРАЕТ».
4. Системной кнопкой «Назад» на Android.

## 🛠️ Стек технологий и разработка

* **Платформа**: [Capacitor](https://capacitorjs.com/) (Android / iOS)
* **Аудиодвижок**: HTML5 Audio API + MediaSession API
* **Хранилище**: IndexedDB (кэширование Blob-аудио) + LocalStorage/Capacitor Preferences
* **Сборка**: Node.js, Gradle, Android SDK

### Команды сборки:
```bash
# Установка зависимостей
npm install

# Запуск тестов (33 автоматических теста)
npm test

# Сборка веб-бандла
npm run bundle

# Компиляция готового Android APK
npm run build:apk
```
